Ready to Monitor Your Applications?

To view the live KALKI-WAF dashboard with real-time data, please run the backend locally.

How to Start the Dashboard Locally:

  1. Clone the repository: git clone https://github.com/Pradyu12/KALKI-WAF.git
  2. Navigate to the project: cd KALKI-WAF
  3. Install dependencies: pip install -r backend/requirements.txt
  4. Start the platform: python3 kalki.py
  5. Access the dashboard: Open your browser to http://localhost:8080

For production deployment, use sudo python3 kalki.py install to set up as a system service.
