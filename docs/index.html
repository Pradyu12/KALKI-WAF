KALKI-WAF

Core Web Application Firewall Platform

Overview

KALKI-WAF is a comprehensive Web Application Firewall platform designed for local deployment without cloud dependencies. It provides enterprise-grade security monitoring and protection for web applications.

Features

Core Security Modules

SIEM, HIDS, FIM, SCA, Vulnerability Assessment, and Active Response capabilities.

Desktop Client

Native desktop application for real-time monitoring and management.

System Service

Can be installed as a systemd service for automatic startup on boot.

API Protection

Admin API key required for write operations to ensure security.

Getting Started

To deploy KALKI-WAF locally:

  1. Clone the repository: git clone https://github.com/Pradyu12/KALKI-WAF.git
  2. Install dependencies: pip install -r backend/requirements.txt
  3. Start the platform: python3 kalki.py
  4. Access the dashboard at http://localhost:8080

For production deployment, install as a system service:

  1. Run with sudo: sudo python3 kalki.py install
  2. The service will start automatically on boot.
