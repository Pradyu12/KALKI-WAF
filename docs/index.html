📋 How to Deploy and Run:

  1. Get the Code:
    git clone https://github.com/Pradyu12/KALKI-WAF.git cd KALKI-WAF
  2. Setup Environment:
    # Install Python dependencies pip install -r backend/requirements.txt # Optional: Create virtual environment python -m venv venv source venv/bin/activate # Linux/Mac # venv\Scripts\activate # Windows
  3. Start the Platform:
    # Start backend + desktop client + browser python3 kalki.py # Or backend only (headless) python3 kalki.py server # Or desktop client only python3 kalki.py desktop
  4. Access the Dashboard:
    Backend API: http://localhost:8080 Dashboard UI: http://localhost:8080 (auto-opens) Desktop App: Runs separately
  5. For Production:
    # Install as system service (auto-start on boot) sudo python3 kalki.py install # Manage service sudo systemctl status kalki-waf sudo systemctl stop kalki-waf sudo systemctl start kalki-waf
